# 10. QUBO 기반 도면 생성과 풀이기 비교

[← 목록으로](README.md)

도면 생성 화면(`/generate/`)의 마지막 단계에서 생성 알고리즘을 하나 또는 여러 개 골라 돌릴 수 있습니다. 실 배치를 QUBO로 만들고, 첨부 가이드(QUBO 비교 알고리즘 선정 가이드)가 권한 비교 세트로 풉니다. 조사 보고서는 [`docs/research/QUBO 평면 생성 알고리즘.md`](../docs/research/QUBO%20평면%20생성%20알고리즘.md), 본문 문헌의 전체 서지와 DOI는 [7번 문서](07-참고-문헌.md) 20~49번입니다.

## 무엇을 QUBO로 만들었나

평면 전체가 아니라 **판상형 템플릿 안에서 어느 실이 어느 칸에 가는가**만 QUBO로 만듭니다(띠별 이차 배정 문제, QAP). 실 폭·깊이 같은 연속 기하와 공간구문 통합도 같은 경로 기반 지표는 2차식이 아니라서, 해를 판상형 문법(`layout.js`)으로 평면으로 풀어 낸 뒤 평가 모델이 채점합니다. 주거 평면을 QUBO로 정식화한 동료 심사 논문은 찾지 못했습니다(가장 가까운 것은 공장 배치: Klar et al. 2022, Wu et al. 2025).

| 항목 | 정식화 (`src/generate/qubo.js`) | 근거 |
| --- | --- | --- |
| 변수 | x(r,s) = 실 r이 칸 s에. 앞 띠(거실·안방·앞 작은방) × 앞 칸, 뒤 띠(주방·현관·공용욕실·다목적실·뒤 작은방) × 뒤 칸. 부부욕실·드레스룸은 안방 뒤에 고정 | Koopmans–Beckmann QAP, 영역 마스킹 |
| 제약 | 실마다 한 칸, 칸마다 한 실: P(Σx − 1)² | Lucas 2014; Glover, Kochenberger & Du 2019 |
| 벌점 P | 1 + 한 변수가 받는 목적 계수 절댓값 합의 최댓값(뒤집기 한 번의 최대 이득) | Ayodele 2022: 순열 QUBO는 작은 유효 벌점이 가장 좋음 |
| 이차 항 | 주방–거실 맞닿음(−8), 현관–거실·현관–주방(−5), 공용욕실–공용 공간(−3), 침실–현관(+4), 뒤 침실 위치, 침실–거실·침실–침실 벽(방음 근사) | 평가 규칙 kitchenLiving·entry·publicBath, 공·사 깊이 |
| 일차 항 | 거실 가운데(거실 중심형), 안방 끝 칸, 현관 가운데 쪽 | Hillier 1987; Choi 2014 |
| 선호 | 고른 공간구문·생활 선호의 항에 배수 1.6~2 | 9번 문서의 선택지 |
| 템플릿 | 앞 띠 작은방 수 = 들어가는 최대 개수와 하나 적게, 두 QUBO를 예산을 나눠 풀고 에너지는 같은 템플릿끼리만 비교 | 1~2시드 시험에서 앞 띠 수를 고정하면 평면 점수가 크게 떨어짐 |

변수는 조건·템플릿에 따라 18~45개입니다(벤치마크 4개 조건). D-Wave Pegasus·Zephyr에서 밀집 클릭 임베딩이 가능한 크기(약 180)보다 작습니다.

## 풀이기 (`src/generate/solvers.js`, 순수 JS)

| 풀이기 | 구현 | 기본값 |
| --- | --- | --- |
| D²TS | 한 변수 뒤집기 tabu + 엘리트 8개·빈도 기반 섭동(γ = n/4, 순위 ∝ j^−1.2) | Glover, Lü & Hao 2010 |
| Path Relinking | 참조 집합 10개, 경로 1/3~2/3 지점을 tabu로 개선 | Wang, Lü, Glover & Hao 2012 |
| Memetic | 개체 20, 균등 교차, tabu 개선 | Lü, Glover & Hao 2010 |
| Tabu (D-Wave 방식) | 다중 시작 tabu, tenure = min(20, ⌊n/4⌋), 읽기 하나에 20ms, 무작위 시작과 최고해 재시작을 번갈아 | dwave-samplers TabuSampler(MST2, Palubeckis 2004)를 다시 구현. D²TS와 다른 알고리즘 |
| tabu 공통 | tenure = n/50 + rand(1..10), 개선 없이 15n이면 멈춤(원-핫 QUBO에 가장 가까운 집합 분할 설정) | HMA SPP 설정 |
| SA | D-Wave 방식 β 범위(ln2/최대 변화, ln100/최소 계수), 기하 스케줄 1000 sweep, 순차 방문, 재시작 | dwave-samplers. **QPU 임시 대체, 잠정 — 양자 결과 아님** |
| SQA | 경로적분, Trotter 16, PT = 0.5, Γ 2.5 → 0.01, J⊥ = −(PT/2)·ln tanh(Γ/PT) | Santoro et al. 2002. 고전 양자 몬테카를로 |
| Parallel Tempering | 사본 8, 기하 β 사다리, 이웃 교환 | Hukushima & Nemoto 1996(원문 미확인, 표준 규칙) |
| Simulated Bifurcation | dSB, a0 = 1, a(t) 0→1, c0 = 0.5/(rms(J)√N), Δt = 0.5, 1000 step. 일차 항은 +1 고정 보조 스핀 | Goto et al. 2021. 보조 스핀 처리는 원 논문 밖의 추론 |
| CP-SAT 방식 | 칸을 차례로 채우는 제약 프로그래밍 분기한정(AllDifferent + 낙관적 하한으로 가지치기) | OR-Tools CP-SAT는 브라우저에서 못 돌려 같은 발상으로 대체. 진짜 CP-SAT는 Python 스크립트(`--solver cpsat`) |
| 정확해(열거) | 원-핫을 지키는 모든 배정(앞 m! × 뒤 k!)을 열거. 벌점이 유효하므로 QUBO 전역 최적 | Gurobi·CP-SAT의 브라우저 안 대체 |

검증: 84㎡·방 3개 QUBO에서 D²TS·PR·Memetic·PT·정확해가 같은 최적에 닿고, 평가 횟수 예산(maxEvals)으로 돌리면 같은 시드에서 결과가 같습니다(`test/model.test.js`). 내보낸 114㎡ QUBO를 Python에서 D-Wave SA·Tabu와 CP-SAT(벌점형·원-핫 제약형 모두)로 풀어 브라우저 정확해와 같은 최적 에너지 −5.30을 확인했습니다.

## 비교 방법 (화면과 실험)

- 같은 시간 예산(풀이기당 0.15·0.3·1초)과 같은 시드. 풀이기마다 좋은 해 최대 4개를 평면으로 풀고, 같은 횟수(30번)로 연속값을 다듬어 가장 좋은 안을 고릅니다.
- **2단계 보고**: QUBO 에너지(최적 도달 여부)와 평면 점수(모델 점수·순위 점수)를 함께 보이고, 둘의 스피어만 상관을 냅니다. QUBO 에너지는 평가 모델의 대리 지표라 에너지 최적이 곧 최고 평면은 아닙니다.
- 화면의 한 번 실행에는 "n = 1, 통계적 비교 불가"를 적고 우승 표시를 하지 않습니다. 실행 기록(풀이기·시드·예산·에너지·점수)을 JSON으로 받을 수 있습니다.
- 논문용 실험은 `npm run qubo:bench`: 조건 4개 × 시드 30개 × 알고리즘 9개. 시간 예산을 기계에서 평가 횟수로 보정해 고정하고(재현 가능), 최적 도달률·TTS₉₉·에너지 차·순위 점수 중앙값(IQR)·Friedman 검정·Holm 보정 Wilcoxon·에너지–점수 상관을 [`results/qubo-benchmark.md`](results/qubo-benchmark.md)에 씁니다(Dunning et al. 2018; Derrac et al. 2011; Rønnow et al. 2014).

## QUBO 가중치를 평가 모델로 다시 맞춤

처음 가중치는 평가 규칙과 문헌을 보고 손으로 정했는데, 1차 실험(아래 '손 가중치' 결과)에서 QUBO 최적이 곧 좋은 평면이 아니었습니다(에너지–점수 ρ = −0.18). 에너지(벌점 제외)가 Σ 가중치 × 항 값으로 가중치에 선형이므로, 평가 모델 점수에 맞춰 다시 정했습니다(`npm run qubo:calibrate`, 결과 [`results/qubo-calibration.md`](results/qubo-calibration.md)).

- 데이터: 조건 20개(59~114㎡, 방 2~4개, 선호 5가지, 다목적실·발코니 유무) × 템플릿 2개의 배치 9,567개를 열거·표본추출해 평면으로 풀고 순위 점수를 쟀습니다. 손 가중치 0인 후보 항 4개(주방 끝 칸, 뒤 침실 끝 칸, 안방–주방, 앞 침실–공용욕실)를 더했습니다.
- 방법 두 가지를 조건 단위 5겹 교차검증(조건을 통째로 빼고 맞춤)으로 비교했습니다. 릿지 회귀(조건·템플릿별 순위 점수)는 전체 순서는 잘 맞추지만(ρ −0.33 → −0.55) 에너지 최소 배치의 평면은 오히려 나빠졌습니다. 그래서 '에너지 최소 배치의 후회(그 조건 최고 점수와의 차)'를 직접 줄이는 무작위 국소 탐색을 썼습니다.

| 가중치 | 에너지–점수 ρ | 에너지 최소 배치의 점수 백분위 | 에너지 최소 배치의 후회 |
| --- | --- | --- | --- |
| 손 | −0.334 | 69.7% | −16.1 |
| 보정(직접, 선택) | −0.533 | 79.2% | **−10.6** |

(빼 둔 조건에서 잰 값.) 화면과 내보내기의 기본 가중치는 보정 값이고, '손으로 정한 값'을 골라 비교할 수 있습니다. 보정 가중치 가운데 몇 개는 손 가중치와 부호가 다릅니다(예: 다목적실–주방 옆은 손 −3, 보정 +). 평가 모델이 실제로 점수를 주는 배치가 처음 가정과 다르다는 뜻이라, 논문에서는 두 가중치를 나란히 보고합니다.

## '풀이기당 시간'의 뜻

각 알고리즘이 QUBO를 푸는 데 쓰는 시간 한도입니다(평면으로 풀고 채점하는 시간은 별도). 같은 한도를 줘야 공정한 비교라서 둡니다(Dunning et al. 2018). 이 크기(변수 18~45개)에서는 tabu 계열·CP-SAT 방식·정확해가 0.1초 안에 QUBO 최적에 닿으므로 시간을 늘려도 평면이 좋아지지 않습니다. SA·SQA·SB·PT는 확률적이라 시간을 늘리면 최적 도달률이 오릅니다(TTS₉₉로 얼마나 필요한지 보고). 평면 품질을 좌우하는 것은 풀이 시간이 아니라 QUBO가 평가 모델을 얼마나 잘 대리하는가이며, 그래서 가중치 보정이 시간 연장보다 효과가 큽니다.

## 결과 (30시드 × 4조건 × 11알고리즘, 풀이기당 100ms를 평가 횟수로 고정)

전체 표와 검정: 보정 가중치 [`results/qubo-benchmark.md`](results/qubo-benchmark.md), 손 가중치 [`results/qubo-benchmark-hand.md`](results/qubo-benchmark-hand.md).

| 알고리즘 | 최적 도달률 (손 → 보정) | 모델 점수 중앙값 (손 → 보정) | 순위 점수 중앙값 (손 → 보정) |
| --- | --- | --- | --- |
| 기존: 모델 직접 탐색 | — | 86.2 | 87.2 |
| D²TS | 100% → 100% | 82.8 → **86.5** | 85.4 → 86.1 |
| Path Relinking | 100% → 100% | 83.3 → **86.2** | 85.3 → 86.0 |
| Memetic | 100% → 100% | 83.2 → **86.4** | 85.5 → 86.0 |
| Tabu (D-Wave 방식) | 100% → 100% | 83.1 → **86.2** | 85.4 → 86.0 |
| 정확해(열거) | 100% → 100% | 83.9 → **86.2** | 85.4 → 86.0 |
| CP-SAT 방식 | 100% → 100% | 79.3 → 84.8 | 83.5 → 84.8 |
| Parallel Tempering | 86% → 53% | 82.5 → 84.9 | 85.1 → 85.3 |
| SA (QPU 대체, 잠정) | 58% → 50% | 82.1 → 85.3 | 84.6 → 85.5 |
| SQA (QPU 대리, 잠정) | 50% → 44% | 83.5 → 84.2 | 84.4 → 84.8 |
| Simulated Bifurcation | 34% → 29% | 82.3 → 83.1 | 83.8 → 84.2 |

- **보정 효과**: QUBO를 정확히 푸는 풀이기들의 평면 모델 점수가 약 3점 올라 '기존: 모델 직접 탐색'(86.2)과 같은 수준이 됐습니다. 순위 점수(모델 + 목표 면적 + 선호)의 차이도 약 1.8점에서 1.2점으로 줄었지만, 기존 탐색이 여전히 유의하게 높습니다(Holm 보정 Wilcoxon 모두 p < 1e−5). 기존 탐색은 연속값(깊이·폭)까지 800번 평가로 맞추고, QUBO 경로는 배치만 QUBO로 정한 뒤 연속값을 30번 다듬기 때문입니다.
- **풀이 성능**: tabu 계열(D²TS·PR·Memetic·Tabu)·CP-SAT 방식·정확해는 두 가중치 모두 매번 최적에 닿습니다. 확률적 풀이기(PT·SA·SQA·SB)는 보정 가중치에서 도달률이 조금 낮아졌는데, 보정 가중치는 계수 차이가 커서 에너지 지형이 더 거칠기 때문으로 보입니다(PT 86% → 53%).
- **같은 최적, 다른 평면**: CP-SAT 방식도 최적 에너지에 닿지만 순위 점수가 낮습니다. 에너지가 같은 최적 배치가 여럿일 때(좌우 대칭 등) 분기한정은 탐색 순서상 먼저 찾은 배치를, 열거는 다른 배치를 내기 때문입니다. 동점 최적해 가운데 무엇을 고르느냐가 평면 점수를 바꾸므로, 풀이기는 동점 해를 여러 개 내고 평가 모델로 다시 고르는 방식(top-k 재순위)이 맞습니다.
- **에너지–점수 상관**: 풀이기가 낸 해(대부분 저에너지)만 보면 ρ = −0.11(보정) / −0.21(손)로 약합니다. 범위가 저에너지 쪽에 몰려 있어서이며, 전체 배치에서 잰 교차검증 ρ는 −0.53(보정) / −0.33(손)입니다.
- **결론**: 이 크기에서는 풀이기 선택보다 QUBO 정식화(가중치)가 평면 품질을 좌우하고, 평가 모델로 가중치를 맞추면 QUBO 경로가 기존 탐색에 근접합니다. 풀이기 사이의 차이는 '최적에 닿는 속도·확률'(TTS₉₉)로 보고합니다.

## D-Wave·정확해 (오프라인)

화면의 'QUBO 내보내기'가 dimod BQM에 가까운 JSON(일차·이차 계수, 오프셋, 벌점, 원-핫 묶음)을 내보내고, [`public/qubo/solve_qubo.py`](../public/qubo/solve_qubo.py)가 이를 SA·Tabu·SQA(dwave-samplers), QPU(`EmbeddingComposite` 또는 `DWaveCliqueSampler`), Leap Hybrid, Gurobi, CP-SAT로 풉니다. `--native`는 정확해 솔버에 원-핫을 등식 제약으로 줍니다(정확해 솔버에는 그 솔버에 맞는 정식화를 준다: Bucher et al. 2024). `--optimum`을 주면 읽기당 성공 확률과 TTS₉₉를 계산합니다. 기본 설정의 SA는 114㎡ QUBO에서 읽기 100번 중 2%만 최적이었습니다(SQA 3%).

QPU 결과에는 체인 끊김 비율·최대 체인 길이·annealing_time·num_reads·QPU access time을 함께 적고, 하이브리드 결과는 순수 QPU 결과와 따로 보고합니다.

## 한계

- 주거 평면 QUBO의 선례가 없어 정식화(항과 가중치)는 설계 가정입니다. 벌점 크기·항 가중치 민감도 분석은 아직 하지 않았습니다.
