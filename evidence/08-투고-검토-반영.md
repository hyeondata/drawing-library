# 8. SCI 투고 검토 반영

[← 목록으로](README.md)

2026-10-22 SCI 투고를 앞두고 심사자 관점에서 모델을 검토했습니다(보고서: [`docs/research/평면 평가 지표 SCI 투고 검토.md`](../docs/research/평면%20평가%20지표%20SCI%20투고%20검토.md)).
예상 지적 12가지 가운데 코드로 고칠 수 있는 것은 v0.3.0에 반영했고, 데이터나 외부 협조가 필요한 것은 남은 과제로 정리했습니다.

## 예상 지적과 대응

심각도: **치명** = 고치지 않으면 게재 불가, **중대** = 대폭 수정 요구, **경미** = 본문 수정으로 대응.

## 검토 중에 새로 찾은 문제: 도면 축척

검토 보고서에는 없었지만, 손상 실험의 판별 타당도 점검에서 **점수와 세대 면적(픽셀)의 상관이 0.61**로 나와 원인을 찾았습니다.

- AI 허브 도면은 모두 약 4963×3509px 종이에 맞춰 그려져 있어, **침실 한 변 중앙값이 도면마다 160~487px로 약 3배 차이**가 납니다. 한 장에 6세대를 그린 도면은 1세대 도면보다 훨씬 작게 그려집니다.
- 그런데 모델은 접촉 길이 40px, 덕트 면적 12,000px² 같은 **고정 픽셀 기준값**을 쓰고 있었습니다. 같은 기준이 도면마다 다른 실제 길이를 뜻했습니다.
- v0.3.0은 도면마다 **침실 한 변 중앙값 ÷ 305px**을 배율로 삼아 길이·면적 기준값을 보정합니다. 벽 간격은 도면 선 굵기를 따라 축척과 무관하므로(간격 중앙값 7~26px이 침실 크기와 무관) 보정하지 않습니다. 접촉 길이는 모서리만 스치는 실이 링크가 되지 않도록 늘리기만 합니다.
- 보정 뒤 ρ(점수, 상대 면적)는 −0.30으로 줄었습니다. 절대 면적(㎡)은 OCR 치수로 축척을 확정해야 쓸 수 있습니다.
- 같은 이유로 '침실 최소 폭(m)'은 '가장 좁은 침실의 상대 폭'으로, 창 길이 기준(81px)은 배율에 맞춰 바꿨습니다.

## 투고 전 남은 일(우선순위)

1. **원천 데이터에서 SPA·STR 번호 짝짓기 확인.** 짝지어지면 문 기반 그래프를 만들어 인접 그래프 지표와의 일치도(실 유형별 스피어만 ρ, 유전형 순서 보존율, Bland–Altman)를 보고합니다. 이 검증 자체가 논문의 기여가 됩니다.
2. **기준 분포 재구축.** SPA 9,095건 → 세대 분리 → 중복 제거 → 침실 수(× 면적대) 층화, 층당 100세대 이상. `npm run baseline`을 원천 데이터 경로로 돌리면 됩니다.
3. **OCR 치수로 축척 확정.** 절대 면적·폭과 면적대 층화를 쓸 수 있게 됩니다.
4. **실제 대 생성 평면 비교.** 생성기 2종 이상, 집단당 200장 이상, Mann–Whitney U·Cliff's δ·AUC.
5. **전문가 쌍대 선호.** 건축가 8~10명, 침실 수를 맞춘 60~100쌍, Krippendorff α와 EPAR(목표 70% 이상).
6. **등재 상태와 DOI 확인.** [7. 참고 문헌](07-참고-문헌.md)의 체크리스트.

결과 파일은 `npm run results`로 다시 만들고, GitHub Actions가 모델과 결과가 맞는지 검사합니다.
