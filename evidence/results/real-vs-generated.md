# 생성 평면 대 실제 한국 아파트 평면: 공간구문으로 구별되는가

> `uv run python real_vs_generated.py` (analysis/) · 실제: 검증(test) 묶음의 서로 다른 평면 2,775개(침실 2~4개, 가중치 맞춤에 쓰지 않음) · 생성: 조건 600개 × 가중치 3종 × 경로 2개(`scripts/real-vs-generated.mjs`)

## 방법

- **분류기 이표본 검정(C2ST; Lopez-Paz & Oquab 2017)**: 실제와 생성 평면을 같은 수로 맞추고(실제는 생성의 침실 수 구성에 맞춰 층화 표집) 그래디언트 부스팅 분류기를 5겹 교차검증해 AUC를 잽니다. 0.5면 분류기가 둘을 구별하지 못합니다.
- 표집·분할을 바꿔 10번 반복한 평균과 95% 구간, 라벨을 섞은 영분포 50번으로 p값을 냅니다.
- 특징(공간구문, 벽 인접 그래프): 거실/침실 통합도 비, 주방/침실 통합도 비, 유전형 τ, 사생활 깊이 차, 현관→거실 깊이, 고리도, 거실 통제값. 평균 통합도는 실 수에 따라 달라 분류 특징에서 빼고 아래 표에만 냅니다.
- **사전에 정한 판정**: AUC 95% 구간 상한 < 0.60 → 실질적으로 구별되지 않음, < 0.70 → 약하게 구별, 그 이상 → 구별됨. 기준선(실제 dev 대 실제 test)이 '같은 모집단'의 값입니다.

## 지표별 차이 (생성기 전체 경로)

## 한계

- 생성기는 판상형 두 띠 문법이라 실제 평면의 형상 다양성(탑상형·ㄱ자 등)을 만들지 못합니다. 이 비교는 공간구문(그래프) 특징에 한정됩니다.
- 공간구문 지표는 실제와 생성 모두 벽 인접 그래프로 쟀습니다(같은 규약).
