# 진단: 생성 평면의 현관→거실 깊이가 실제보다 큰 이유

> 생성: 2026-11-04 · `node scripts/entrance-living-diagnosis.mjs` · 실제 dev 도면 325장(검증 묶음 제외, 15장마다 1장)의 침실 2~4개 세대 869개 · 생성 평면은 `evidence/results/generated-plans.jsonl`

## 1. 측정 차이가 아니다

- 실제 dev 세대의 **99.4%**에서 현관이 거실과 맞닿고, 현관→거실 깊이 1이 99.4%입니다. 실제와 생성 평면은 같은 `analyze()`(벽 인접 그래프)로 쟀으므로 라벨 규칙 차이로 생긴 차이가 아닙니다.
- 현관과 맞닿는 실 유형(세대 비율): 거실 99.4%, 기타 82.9%, 화장실 61.9%, 주방 25.4%, 침실 12.4%, 드레스룸 5.2%.

## 3. 원인

- **실제 빈도로 맞춘 가중치(최대 엔트로피)의 QUBO 최적해는 현관이 100% 거실에 붙습니다.** QUBO 항 구성 자체는 한국 평면의 현관–거실 관계를 표현할 수 있습니다.
- 손 가중치와 J 보정 가중치의 QUBO 최적해는 13~18%만 붙습니다. J 보정에서 `entranceLiving`이 0이 되었고(J가 이 관계를 보상하지 않음), 현관–주방 맞닿음이 실제(16.8%)보다 훨씬 강하게 보상되기 때문입니다(evidence/results/qubo-maxent.md).
- 생성기 전체 경로(SA + J)에서는 세 가중치 모두 33~39%로 내려갑니다. 순위 점수 J는 평가 모델 점수 + 목표 면적 부합 + 좁은 실 감점이고, 평가 모델 규칙 `livingNear`는 깊이 2까지 통과시키므로, 면적 부합이 조금 나은 깊이 2 평면이 뽑힙니다.
- 결론: 어긋남은 **순위 점수 J(현재 기준)와 J에 맞춘 가중치**에서 생깁니다. 한국 실제 평면의 현관–거실 직결(dev 98% 이상)은 데이터로 뒷받침되는 구조 규칙이며, 이 진단은 검증(test) 묶음과 분류기 결과를 쓰지 않고 dev 데이터만으로 원인을 정했습니다.
