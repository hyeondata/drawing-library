## 읽는 법과 한계

- β는 결과를 보고 고른 값이 아니라 dev A의 실제 평균에 맞춘 값이다(사전 등록 설계 evidence/18 §2.3). 판정은 B에서, 최종은 test 1회.
- 모든 그래프는 벽 인접 그래프다. M2·M3는 출입 그래프와 같음이 확인된 양(door-vs-wall, dev 10세대)이고, M1은 같은 규약 안의 비교, M4·M5는 참고.
- 생성 쪽은 판상형 정렬 모드 틀 안의 평면뿐이다. 실제와의 남은 거리(기준선 대비)는 틀이 설명하지 못하는 부분을 포함한다.
- 실제 쪽은 같은 그래프를 하나로 묶은 서로 다른 그래프 집합이다(빈도 정보는 쓰지 않음).
