# RQ2: RRA 목적의 정확 QUBO와 O6(비율)의 Dinkelbach 풀이

> `SPECS=rq4 uv run python -m syntax_qubo.rra_exact` · 템플릿 160개 · 뿌리 거실·현관·주방

- 왜 필요한가: 복도 존재가 배치에 따라 바뀌어 노드 수 k가 템플릿 안에서 달라진다(73/160). 그래서 총깊이 최소와 RRA 최소의 최적 배치가 다른 템플릿이 있다(거실 11개, 현관 23개). RQ4 판정(RRA)과 QUBO 목적을 맞추려고 RRA를 정확한 이차식으로 넣었다.
- 검증 1(정준 상태 에너지 = 그래프 RRA): 템플릿 160 × 뿌리 3 × 모든 배치 = 54,252건, 최대 오차 **6.2e-13**.
- 크기: 변수 중앙값 340 (최대 650), 이차항 중앙값 2638 (최대 7357). 총깊이 목적과 같은 변수 — RRA는 x·h 곱 항만 더함.
- 검증 2(O6 Dinkelbach): 160/160 템플릿에서 수렴값 = 비율 최적, 반복 횟수 중앙값 2 (최대 4). 각 반복은 정확 RRA 식의 선형 결합이라 하나의 정확 QUBO다.
- 정확 QUBO로 쓰지 못한 것: O9(거실 선택도 = 최단 경로 수 비율)는 경로 다중도를 세는 변수가 필요해 이 인코딩의 이차식으로 쓸 수 없다. O7h(가장 통합된 복도)는 복도가 있을 때만 뿌리가 되고 노드 수도 함께 바뀌어 3차 항이 생긴다 — 보조 변수로 2차화할 수는 있으나 구현하지 않았다. 두 목적은 RQ4에서 열거로만 판정했다.
