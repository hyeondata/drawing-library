# 17. AI 허브 아파트 평면도 전체 데이터 분석과 설계 변경

이전 판은 Sample 20도면에서 나온 35세대를 기준으로 선택지를 만들고, 같은 35세대 분포와의 근접도로 생성 결과를 채점했습니다.
이 문서는 그 표본 분석을 AI 허브 SPA 라벨 전체(TL_SPA, 9,645건)로 바꾼 방법과 그 결과로 바뀐 설계를 정리합니다.
**숫자는 모두 [`results/aihub-summary.md`](results/aihub-summary.md)에 있습니다.** 그 표는 분석 스크립트가 직접 쓰므로 손으로 옮겨 적지 않습니다.
재현: `node scripts/build-aihub-stats.mjs <TL_SPA 폴더>` → `src/generate/aihub-stats.js`, `evidence/results/aihub-summary.md`.

## 기준 세대를 고르는 방법

1. 9,645건을 같은 분석기(`src/model/spa.js`)로 세대 분리합니다: 23,116세대.
2. 아파트 평면도(APT_FP)만 씁니다. 생성기가 판상형 아파트용이고, APT_CS에는 필수 실을 모두 갖춘 세대가 없으며, 단독·연립은 구조가 다릅니다.
3. 필수 실(현관·거실·주방·침실·화장실)이 모두 있는 세대만 남깁니다: 18,961세대.
4. 실 개수·면적비·공간구문 변수가 똑같은 세대는 하나로 셉니다: **7,912세대**. 같은 평면이 여러 단지·도면에 반복돼(한 평면이 157번 나오기도 함) 그대로 세면 반복 평면이 분포를 끌고 갑니다.

> 정정: 이 브랜치의 첫 커밋은 4단계에서 실 개수 객체의 키 순서까지 비교해, 같은 평면을 다른 세대로 세는 바람에 15,018세대로 적었습니다. 키를 정렬해 비교하도록 고쳤고 모든 수치를 다시 냈습니다.

## 바뀐 설계

| 항목 | 이전(35세대 표본) | 지금(고유 세대 7,912개) |
| --- | --- | --- |
| 생성 목적함수 | 표본 분포 근접도 45% + 면적 25% + 선호 30% | 규칙 충족률 45% + 면적 25% + 선호 30% − 감점(채점 없음) |
| 침실 수 선택지 | 2~4개 | 1~5개. 6개 이상은 고유 153세대 중 64세대(42%)에 거실이 2개라 두 세대가 합쳐진 세대 분리로 보고 뺌 |
| 화장실 | 1~2개 | 1~3개. 3개 이상이 방 4개 세대의 31%, 방 5개의 56% |
| 거실·작은방·안방·주방·현관·화장실 목표 | 표본 전체 분위수 | **고른 침실 수 세대의 분위수**(작은방 중앙값이 방 2개 11.8% → 방 5개 5.6%) |
| 실 구성 기본값 | 고정 | 고른 침실 수 세대의 절반 이상이 가진 실을 켬(직접 바꾸면 그대로) |
| 복도·홀 | 제한 없음 | 생성 평면의 '기타' 면적비가 같은 침실 수 세대의 p75를 넘으면 면적 오차로 셈 |
| 선택 규칙 | 없음(모두 채점) | 실제 통과율 90% 미만인 규칙만 선택 규칙(`OPTIONAL_BELOW`): 안방 부속실 80.2%. 채광 91.3%는 필수 |
| 선호 점수 | 표본 백분위 | 실제 분포 p10 → 0점, p90 → 100점 |
| 축척 기준 `referenceBedSide` | 305px(표본 80건) | 297px(전체 도면별 중앙값) |
| 자유형 기준 세대 | 표본 32세대 | APT_FP 전체에서 침실 수별 15세대(원본이 접근 규칙을 통과하는 세대만) |

벽 간격 기준(실내 32px, 외벽 50px)은 실 쌍 최소 거리 분포(중앙값 15·18px) 안에 벽 두께 대부분이 들어가고, 실제 세대의 도달성 통과율이 94.3%라 그대로 둡니다.

## 남은 일

- 라벨에 축척이 없어 전용면적 선택지(59~135㎡)는 대표 주택형이며 데이터에서 정하지 않습니다.
- 화장실 4개 이상(고유 세대의 4%)은 지원하지 않습니다.
