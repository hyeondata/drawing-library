# 17. AI 허브 아파트 평면도 전체 데이터 분석과 설계 변경

이전 판은 Sample 20도면에서 나온 35세대를 기준으로 선택지를 만들고, 같은 35세대 분포와의 근접도로 생성 결과를 채점했습니다.
이 문서는 그 표본 분석을 AI 허브 SPA 라벨 전체(TL_SPA, 9,645건)로 바꾼 방법과 그 결과로 바뀐 설계를 정리합니다.
**숫자는 모두 [`results/aihub-summary.md`](results/aihub-summary.md)에 있습니다.** 그 표는 분석 스크립트가 직접 쓰므로 손으로 옮겨 적지 않습니다.
재현: `node scripts/build-aihub-stats.mjs <TL_SPA 폴더>` → `src/generate/aihub-stats.js`, `evidence/results/aihub-summary.md`.

## 기준 세대를 고르는 방법

1. 9,645건을 같은 분석기(`src/model/spa.js`)로 세대 분리합니다. **현관 하나 = 세대 하나**입니다. 현관 라벨 두 개가 8px 미만으로 붙어 있으면 한 현관이 쪼개진 것으로 보고 묶습니다(APT_FP 현관 쌍 거리는 0~7px 약 1,990쌍과 10~22px 약 90쌍으로 나뉘고 8px에는 0쌍). 현관이 없는 도면 59건은 거실을 기준으로 한 세대로 봅니다. 붙은 라벨이 정말 한 집인지는 묶지 않고 따로 나눠 확인했습니다: 541개 도면의 1,993쌍 모두에서 한쪽만 거실·침실이 있는 세대가 되고 다른 쪽은 현관 조각만 남았습니다(둘 다 세대가 된 쌍 0, `scripts/verify-entrance-split.mjs`). 그래서 현관 라벨 수(21,383)는 세대 수가 아닙니다. APT_FP는 현관 라벨 21,383개 → 현관 묶음 19,390개 + 현관 없는 도면 59건 = **19,449세대**이고, 도면 7,275건 모두에서 세대 수 = 현관 묶음 수입니다(`scripts/verify-units.mjs`). 전체 22,732세대.
2. 아파트 평면도(APT_FP)만 씁니다. 생성기가 판상형 아파트용이고, APT_CS에는 필수 실을 모두 갖춘 세대가 없으며, 단독·연립은 구조가 다릅니다.
3. 필수 실(현관·거실·주방·침실·화장실)이 모두 있는 세대만 남깁니다: 18,931세대. 빠진 518세대는 대부분 도면 가장자리에 걸려 주방·거실이 없는 이웃 세대 조각입니다.
4. 실 개수·면적비·공간구문 변수가 똑같은 세대는 하나로 셉니다: **7,970세대**. 같은 평면이 여러 단지·도면에 반복돼(한 평면이 120번 나오기도 함) 그대로 세면 반복 평면이 분포를 끌고 갑니다.

> 정정 두 가지: (1) 첫 커밋은 반복 세대를 판정할 때 실 개수 객체의 키 순서까지 비교해 같은 평면을 다른 세대로 세는 바람에 15,018세대로 적었습니다. (2) 이전 세대 분리는 거실·침실이 없는 조각을 가장 많이 맞닿은 세대에 합쳐, 멀리 떨어진 이웃 세대의 현관 조각이 397세대에 잘못 들어갔습니다. 둘 다 고치고 모든 수치를 다시 냈습니다.

## 바뀐 설계

| 항목 | 이전(35세대 표본) | 지금(고유 세대 7,970개) |
| --- | --- | --- |
| 생성 목적함수 | 표본 분포 근접도 45% + 면적 25% + 선호 30% | 규칙 충족률 45% + 면적 25% + 선호 30% − 감점(채점 없음) |
| 침실 수 선택지 | 2~4개 | 1~5개. 6개 이상은 고유 151세대 중 62세대(41%)에 거실이 2개라 두 세대가 합쳐진 세대 분리로 보고 뺌 |
| 화장실 | 1~2개 | 1~3개. 3개 이상이 방 4개 세대의 36%, 방 5개의 57% |
| 거실·작은방·안방·주방·현관·화장실 목표 | 표본 전체 분위수 | **고른 침실 수 세대의 분위수**(작은방 중앙값이 방 2개 11.8% → 방 5개 5.6%) |
| 실 구성 기본값 | 고정 | 고른 침실 수 세대의 절반 이상이 가진 실을 켬(직접 바꾸면 그대로) |
| 복도·홀 | 제한 없음 | 생성 평면의 '기타' 면적비가 같은 침실 수 세대의 p75를 넘으면 면적 오차로 셈 |
| 선택 규칙 | 없음(모두 채점) | 실제 통과율 90% 미만인 규칙만 선택 규칙(`OPTIONAL_BELOW`): 안방 부속실 79.8%. 채광 90.5%는 필수 |
| 선호 점수 | 표본 백분위 | 실제 분포 p10 → 0점, p90 → 100점 |
| 축척 기준 `referenceBedSide` | 305px(표본 80건) | 297px(전체 도면별 중앙값) |
| 자유형 기준 세대 | 표본 32세대 | APT_FP 전체에서 침실 수별 15세대(원본이 접근 규칙을 통과하는 세대만) |

벽 간격 기준(실내 32px, 외벽 50px)은 실 쌍 최소 거리 분포(중앙값 15·18px) 안에 벽 두께 대부분이 들어가고, 실제 세대의 도달성 통과율이 94.3%라 그대로 둡니다.

## 남은 일

- 라벨에 축척이 없어 전용면적 선택지(59~135㎡)는 대표 주택형이며 데이터에서 정하지 않습니다.
- 화장실 4개 이상(고유 세대의 6%)은 지원하지 않습니다.
