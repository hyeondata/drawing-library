# 11. 계산 원리: 철학, 식, 계산 순서

[← 목록으로](README.md)

이 문서는 사이트가 **무엇을 어떤 생각으로 어떻게 계산하는지**를 처음부터 끝까지 한곳에 모은 것입니다. 본문에 이름만 적은 문헌의 전체 서지와 DOI는 [7번 문서](07-참고-문헌.md)(평가 1~19번, 생성·QUBO·이미지 20~52번)에 있습니다. 지표를 고른 이유와 근거 논문은 [2~5번 문서](README.md), 숫자 결과는 [`results/`](results/)에 있고, 여기서는 식과 계산 순서를 설명합니다. 식의 기호는 코드의 변수 이름을 따랐고, 각 절 끝에 해당 코드 파일을 적었습니다.

## 1. 철학: 여섯 가지 원칙

1. **"좋은 평면"이 아니라 "실제 한국 평면과 얼마나 닮았나 + 유효한가"를 잰다.**
   좋은 평면의 보편 기준은 없습니다. 대신 실제로 지어진 아파트(AI 허브 라벨)를 정답지로 보고, 평가 대상이 그 분포 안 어디쯤에 있는지 잽니다. 그래서 점수는 '규범'이 아니라 '관행과의 거리'입니다.
2. **근거가 있는 지표만 쓰고, 근거와 한계를 함께 적는다.**
   지표마다 SCI/SCIE·SSCI 문헌을 붙이고, 변별력이 없거나 근거가 약한 지표는 빼거나 참고값(가중치 0)으로 내립니다([6번 문서](06-제외-보류-지표.md)).
3. **기준값은 사람이 정하지 않고 데이터에서 나오게 한다.**
   점수의 기준은 표본 분포의 중앙값과 강건 척도(Qn)이고, 생성 화면의 선택지(거실 크기 등)도 표본 분위수입니다. 사람이 정한 값(임계값, 가중치)은 모두 `config.js`에 모으고 민감도 분석을 합니다.
4. **이상치에 흔들리지 않는 통계를 쓴다.**
   표본이 작고(35세대) 꼬리가 길어서 평균·표준편차 대신 중앙값·Qn·백분위를 씁니다.
5. **"유효한가"와 "얼마나 좋은가"를 섞지 않는다.**
   필수 실이 없거나 끊긴 평면은 점수가 높아도 '유효하지 않음'으로 따로 표시합니다(관문 규칙, 비보상형 판정).
6. **계산은 재현 가능해야 한다.**
   같은 코드가 브라우저·CLI·테스트에서 돌고, 무작위가 들어가는 계산(민감도 분석, 생성, QUBO 풀이)은 모두 시드를 고정합니다.

## 2. 전체 흐름

```
[입력]  AI 허브 라벨(JSON) ── 이미지(PNG·JPG) ── 생성 조건(8단계 선택)
          │                    │ 영역 분할 + 글자 인식      │ 판상형 문법 / QUBO + 풀이기
          ▼                    ▼                            ▼
       COCO 공간 라벨(실 = 다각형 + 종류)  ◀───────────────┘
          │
          ▼  축척 보정 → 인접 그래프 → 세대 분리
       세대마다 지표 계산(공간구문 · 면적 · 형태 · 외기) + 규칙 판정
          │
          ▼  기준 분포(같은 도면 제외, 같은 침실 수 층)와 비교
       지표 점수(강건 z 또는 백분위) → 영역 점수 → 종합 점수·등급 + 유효성
```

이미지와 생성은 결국 **같은 COCO 공간 라벨**을 만들어 같은 평가 모델로 들어갑니다. 그래서 세 경로의 점수를 같은 척도로 비교할 수 있습니다.

## 3. 평가 모델

### 3.1 입력 정규화: 축척 보정

AI 허브 도면은 모두 같은 크기의 종이(약 4963×3509px)에 맞춰 그려져 있어서, 같은 1px가 도면마다 다른 실제 길이입니다(침실 한 변 중앙값이 160~487px로 약 3배 차이). 절대 길이를 모르므로 **침실을 자로** 씁니다.

$$s = \operatorname{clip}\!\left(\frac{\operatorname{median}_{\text{침실}}\sqrt{\text{면적}}}{305},\ 0.4,\ 2.5\right)$$

305px는 표본 침실 한 변의 중앙값입니다. 길이·면적 기준값만 s에 맞춥니다.

| 기준값 | 배율 1일 때 | 보정 |
| --- | --- | --- |
| 최소 접촉 길이 | 40px | × max(1, s) (줄이면 모서리만 스치는 실이 이웃이 됨) |
| 덕트로 볼 '기타' 실 최대 면적 | 12,000px² | × s² |
| 창을 낼 수 있는 외기 길이 | 81px | × s |
| 벽 간격(같은 벽을 공유한다고 볼 거리) | 32px(외벽 쪽 50px) | 보정 안 함(선 굵기는 축척과 무관) |

코드: `src/model/spa.js` (`drawingScale`, `scaledThresholds`)

### 3.2 인접 그래프와 세대 분리

두 실 i, j가 **벽 간격 τ 이내**에 있고 **맞닿은 길이가 최소 접촉 길이 이상**이면 링크를 둡니다. 맞닿은 길이는 한 실의 둘레를 4px 간격으로 따라가며 다른 실과의 거리가 τ 이하인 구간을 더한 것입니다.

- 문 정보가 공간 라벨에 없으므로 이것은 **출입 그래프가 아니라 인접 그래프**입니다(벽을 맞대면 연결). 이 한계를 지표 이름에 밝힙니다.
- 현관마다 연결된 실을 모아 세대를 나누고, 엘리베이터홀·계단실은 공용부로 뺍니다.
- 공간구문 계산에서는 작거나 현관에서 닿지 않는 '기타'(덕트·PS)를 빼고, 현관에 **세대 밖 노드**를 하나 붙입니다(문헌 값과 같은 규약).

### 3.3 공간구문 지표

그래프에서 노드 i의 깊이 d(i, j)는 최단 단계 수입니다(너비 우선 탐색). 노드 수를 K라 할 때(Hillier & Hanson 1984):

$$\text{MD}_i = \frac{\sum_j d(i,j)}{K-1},\qquad \text{RA}_i = \frac{2(\text{MD}_i - 1)}{K-2},\qquad \text{RRA}_i = \frac{\text{RA}_i}{D_K},\qquad \text{통합도}_i = \frac{1}{\text{RRA}_i}$$

D_K는 다이아몬드형 기준 그래프의 값으로, 실 수가 다른 평면을 비교할 수 있게 RA를 정규화합니다.

$$D_K = \frac{2\left(K\left(\log_2\frac{K+2}{3} - 1\right) + 1\right)}{(K-1)(K-2)}$$

통제도는 이웃마다 1/(그 이웃의 연결 수)를 더한 값입니다. 이 값들로 지표를 만듭니다.

| 지표 | 식 | 뜻 |
| --- | --- | --- |
| 거실/침실 통합도 비 | 거실 통합도 ÷ 침실 평균 통합도 | 거실 중심성(Byun & Choi 2016) |
| 주방/침실 통합도 비 | 주방 평균 통합도 ÷ 침실 평균 통합도 | 주방의 중심성 |
| 유전형 부합도 τ | 5유형(거실·주방·현관·침실·화장실) 평균 통합도의 순서와 기준 순서(거실 > 주방 > 현관 > 침실 > 화장실)의 Kendall τ_b | 한국 거실 중심 유전형(Hillier 1987; Choi 2014). 5유형이 다 있을 때만 |
| 유전형 프로필 거리 | 5유형 통합도를 평면 안에서 z로 표준화한 벡터와, 기준 분포의 성분별 중앙값 벡터 사이의 유클리드 거리 | τ의 연속판 |
| 공·사 깊이 차 | (침실·드레스룸 평균 깊이) − (거실·주방 평균 깊이), 현관 기준 | 사생활 위계(Park 2024; Ham & Lee 2017) |
| 기능실 평균 통합도(실 수 보정) | 평균 통합도에서 기준 분포의 회귀 a + b·ln(기능실 수)를 뺀 잔차 | D값 정규화에 남은 실 수 의존성 제거 |
| 거실 통제값(참고) | 거실 통제도 | 가중치 0 |

코드: `src/model/syntax.js`, `src/model/spa.js` (`analyzeUnit`)

### 3.4 면적·형태·외기 지표

- **면적비**: 세대 전체 면적 중 거실·주방·침실·화장실·발코니가 차지하는 비율, 공용/개인 면적비 = (거실 + 주방 + 현관) ÷ (침실 + 드레스룸), 안방/다른 침실 면적비 = 가장 큰 침실 ÷ 나머지 침실 평균.
- **형태**: 거실·침실·주방마다 회전 최소 외접 사각형(MBR, 볼록 껍질의 각 변 방향으로 돌려 가며 가장 작은 사각형)을 구합니다(Rosin 1999).
  - 직사각형도 = 실 면적 ÷ MBR 면적(면적 가중 평균).
  - 종횡비 = MBR 긴 변 ÷ 짧은 변(면적 가중 평균).
  - 가장 좁은 침실의 상대 폭 = 가장 좁은 침실의 MBR 짧은 변 ÷ (305·s).
- **외기 접면비**: 거실·침실·주방 둘레 가운데, 발코니·실외기실이 아닌 다른 실과 맞닿지 않은 길이의 비율(Ju & Oh 2020).

$$\text{외기 접면비} = \frac{\sum_{\text{거실·침실·주방}} \left(\text{둘레} - \text{실내 공간과 맞닿은 길이}\right)}{\sum \text{둘레}}$$

### 3.5 규칙(정합성)

규칙마다 0~1의 충족 비율 ratio와 가중치를 둡니다.

| 규칙 | 충족 비율 | 가중치 | 관문 |
| --- | --- | --- | --- |
| 필수 실(현관·거실·주방·침실·화장실) | 있는 유형 수 ÷ 5 | 2 | ✓ |
| 모든 실이 현관에서 이어짐 | 1 − 끊긴 실 ÷ 실 수(덕트 제외) | 2 | ✓ |
| 거실이 가장 통합된 기능실 | 1(1위) · 0.5(주방만 앞섬) · 0 | 2 | |
| 침실을 거치지 않고 다른 주요 실에 갈 수 있음 | 1 − 통과 침실 ÷ 침실 수 | 2 | ✓ |
| 거실이 현관에서 2단계 이내 | 0 또는 1 | 1 | |
| 현관이 거실·주방·복도로 바로 열림 | 0 또는 1 | 1 | |
| 주방과 거실이 맞닿음 | 0 또는 1 | 1 | |
| 침실을 거치지 않는 공용 화장실 | 0 또는 1 | 1 | |
| 모든 거실·침실이 외기·발코니에 접함 | 1 − 막힌 실 ÷ 실 수 | 1 | |
| 안방에 딸린 화장실(·드레스룸) | 맞닿은 부속실 ÷ 필요한 부속실 | 1 | |

'통과 침실'은 그 침실을 그래프에서 지웠을 때 현관에서 다른 주요 실(현관·거실·주방·침실·다목적공간)에 못 가게 되는 침실입니다.

### 3.6 점수 계산

**① 기준 분포 고르기.** 평가 도면의 모든 세대를 기준에서 뺍니다(자기 자신과 비교하지 않음). 같은 침실 수의 세대가 15개 이상이면 그 층과만 비교합니다(층화).

**② 강건 척도 Qn** (Rousseeuw & Croux 1993). 모든 쌍의 차 |x_i − x_j|를 정렬해 k번째 값을 씁니다.

$$Q_n = 2.2219 \cdot d_n \cdot \{|x_i - x_j|;\ i<j\}_{(k)},\qquad k = \binom{h}{2},\ h = \lfloor n/2 \rfloor + 1$$

d_n은 작은 표본 보정 계수입니다. MAD보다 정규분포 효율이 높고(약 82% 대 37%) 붕괴점은 같습니다(50%).

**③ 지표 점수.** 연속 지표는 강건 z, 값이 몇 개뿐인 이산 지표(τ, 공·사 깊이 차)와 Qn = 0인 지표는 백분위로 채점합니다.

$$z = \frac{x - \operatorname{median}}{Q_n},\qquad \text{점수} = 100 \cdot \max\left(0,\ 1 - \frac{|z|}{3}\right)$$

방향이 정해진 지표(예: 외기 접면비는 높을수록 좋음)는 좋은 쪽으로 벗어나면 100점입니다. 백분위 점수는 경험적 누적분포 F(동점은 절반)로 셉니다.

$$\text{양측: } 100 \cdot 2\min(F, 1-F),\qquad \text{높을수록: } 100\min(1, F/0.5),\qquad \text{낮을수록: } 100\min\left(1, \frac{1-F}{0.5}\right)$$

**④ 영역 점수와 종합 점수.** 영역 점수는 지표 점수의 가중 평균(기능실 평균 통합도 0.5, 거실 통제값 0, 나머지 1), 규칙 영역은 100 × Σ(가중치 × ratio) ÷ Σ가중치입니다.

$$\text{종합} = \frac{30\cdot\text{공간구문} + 20\cdot\text{면적} + 10\cdot\text{형태} + 10\cdot\text{외기} + 30\cdot\text{정합성}}{100}$$

**⑤ 유효성과 등급.** 관문 규칙(필수 실·연결·침실 비통과) 가운데 하나라도 통과하지 못하면 '유효하지 않은 평면'으로 따로 표시하고, 단일 점수가 필요할 때만 69점을 상한으로 겁니다(비보상형 집계, Munda & Nardo 2009). 등급은 A ≥ 90, B ≥ 80, C ≥ 70, D ≥ 60, 나머지 F입니다.

**⑥ 불확실성.** 가중치(Dirichlet)·0점 기준·관문 상한·채점 방식·집계 방식을 2,000번 바꿔 다시 채점하는 몬테카를로 민감도 분석과, 도면 단위 부트스트랩 1,000번을 합니다(Saisana et al. 2005). 결과: [`results/sensitivity.md`](results/sensitivity.md).

코드: `src/model/index.js`, `src/model/config.js`, `scripts/sensitivity.mjs`

## 4. 이미지에서 라벨 만들기

1. **선 찾기**: 회색조로 바꾸고 Otsu 임계값(클래스 간 분산 최대)으로 어두운 선(벽·문·글자)을 찾습니다. 끊긴 선은 팽창(닫힘)으로 잇습니다.
2. **영역 찾기**: 선이 아닌 빈 칸의 연결 요소를 구하고, 종이 테두리에 닿거나 너무 작거나(0.08% 미만) 너무 큰(20% 초과) 것을 뺍니다. 실 이름 상자·가구처럼 한 실 안에 갇힌 조각은 구멍 채우기로 그 실에 합칩니다.
3. **실 이름 읽기**: Tesseract.js(한국어)로 시트 폭의 80·60·50%(가로 약 3970·2980·2480px) 세 번 읽어 합칩니다(샘플 12장에서 이 조합이 이름 178개/192개를 찾고 시간은 60%).
4. **이름 맞추기**: 한글을 자모(초성·중성·종성)로 풀어 편집 거리로 사전과 비교합니다.

   $$\text{유사도} = 1 - \frac{\text{편집거리}(\text{자모열}_1, \text{자모열}_2)}{\max(\text{길이}_1, \text{길이}_2)} \ge 0.65$$

   동점이면 첫 자모가 같은 이름을 고르고, 겹치는 인식은 (유사도 × 이름 길이)가 큰 쪽을 남깁니다("실외기실"의 꼬리 "기실"이 "거실"이 되는 것을 막음).
5. **라벨로**: 영역 경계를 무어 이웃 추적으로 따고 더글러스–포이커로 단순화해, 시트 폭 4963px로 늘린 COCO 공간 라벨을 만듭니다.

코드: `src/image/segment.js`, `src/image/ocr.js`, `src/image/room-names.js`

## 5. 도면 생성

### 5.1 선택지 → 목표

선택지는 라벨에서 계산합니다(전용면적 = 세대 면적 − 발코니 − 실외기실).

- 거실 목표 면적 = 전용면적 × (거실 면적비의 하위 25%·중앙값·상위 25%·상위 10% 중 고른 것)
- 작은방 = 전용면적 × 작은방 면적비 분위수, 안방 = 작은방 × (안방/작은방 비 분위수)
- 주방·현관·욕실·드레스룸·다목적실 = 기준 세대 중앙값
- 최소 면적: 작은방 6.5㎡, 안방 9.9㎡, 욕실 3.0㎡, 현관 2.2㎡, 드레스룸 2.5㎡

### 5.2 판상형 문법

앞(남측) 띠에 거실과 침실, 뒤 띠에 주방·현관·욕실·드레스룸·다목적실을 두고, 안방 뒤에 부속실을 붙이며, 작은방이 얕으면 그 뒤를 복도로 씁니다. 띠의 폭 나누기는 **최소 폭을 먼저 주고 남는 폭을 원하는 폭의 초과분에 비례해** 나눕니다.

$$w_i = m_i + (W - \textstyle\sum m)\cdot\frac{\max(0,\ d_i - m_i)}{\sum_j \max(0,\ d_j - m_j)}$$

m_i는 최소 폭(욕실 1.5m, 현관 1.2m, 침실 2.4m, 안방 3.0m, 거실 3.6m), d_i는 원하는 폭(면적 ÷ 깊이)입니다. 문은 규칙으로 답니다(침실은 복도 > 거실 > 현관 > 주방 쪽, 부속실은 안방 쪽, 공용 공간끼리는 개구부). 창은 바깥 벽에, 설비는 문 맞은편 벽에 둡니다.

### 5.3 목적함수

$$J = 0.45\cdot\text{모델 점수} + 0.25\cdot\text{면적 부합} + 0.30\cdot\overline{\text{선호 점수}} - 40\cdot[\text{무효}] - 15\cdot(\text{좁은 실} + \text{문 동선 문제})$$

$$\text{면적 부합} = \max\left(0,\ 100 - 250\cdot\overline{\left|\frac{\text{실제} - \text{목표}}{\text{목표}}\right|}\right)\quad(\text{거실·주방·안방·작은방 평균})$$

선호 점수는 각 선택지에 묶인 평가 지표·규칙의 점수 평균입니다(예: 거실 중심형 = 평균(100 × 거실 중심 규칙, τ 점수)). 방음은 평가 지표가 없어 배치 근사를 씁니다.

$$\text{소음 노출} = \frac{\sum_{\text{침실}} \left(\text{거실·주방·현관과 맞댄 길이} + 0.5\cdot\text{다른 침실과 맞댄 길이}\right)}{\sum_{\text{침실}} \text{둘레}},\qquad \text{방음 점수} = \text{평균}\left(100\max\left(0, 1 - \frac{\text{소음 노출}}{0.35}\right),\ \text{공·사 깊이 점수}\right)$$

**문 동선 점검**: 문·개구부로 만든 그래프에서 현관부터 너비 우선 탐색으로 못 가는 실과, 침실을 지나야만 갈 수 있는 실을 셉니다(평가 모델은 인접 그래프라 이것을 못 봄).

'기존: 모델 직접 탐색'은 이 J를 무작위 400개 + 상위 4안에서 국소 탐색 400번으로 최대화합니다.

## 6. QUBO: 실 배치를 이진 최적화로

### 6.1 왜 일부만 QUBO인가

평면 전체를 이진 변수로 쓰면 기하가 폭발하고(직사각형 N개에 스핀 3N³), 통합도처럼 경로에 기대는 지표는 2차식이 아닙니다. 그래서 **위상(어느 실이 어디)만 QUBO로 정하고, 치수는 문법이, 품질은 평가 모델이** 맡습니다. 건축의 '위상 먼저, 치수 나중' 2단계 접근과 같습니다.

### 6.2 변수와 에너지

변수 x(r, s) = 1이면 실 r이 칸 s에 갑니다. 앞 띠(거실·안방·앞 작은방) × 앞 칸, 뒤 띠(주방·현관·공용욕실·다목적실·뒤 작은방) × 뒤 칸으로, 띠마다 정사각 배정 문제(QAP)입니다(변수 18~45개).

$$E(x) = \underbrace{\sum_t w_t\,\phi_t(x)}_{\text{선호·인접 항}} + P\sum_{g \in \text{원-핫 묶음}} \Big(\sum_{v\in g} x_v - 1\Big)^2$$

- **φ_t(x)**: 항 t의 값(가중치 1일 때의 기여, 선호를 고르면 1.6~2배). 예:
  - 주방–거실 맞닿음 φ = Σ x(거실, i)·x(주방, j)·ov(i, j). ov(i, j)는 앞 칸 i([i/m, (i+1)/m])와 뒤 칸 j([j/k, (j+1)/k])가 위아래로 겹치는 비율입니다.
  - 거실이 가운데에서 먼 정도 φ = Σ_s x(거실, s)·|(s + 0.5)/m − 0.5|.
  - 항은 20개(인접 13개, 위치 7개, 4개는 보정에서 더한 후보 항)입니다.
- **원-핫 벌점**: 실마다 칸 하나, 칸마다 실 하나. 이진 변수에서 x² = x이므로 다음처럼 펼쳐 QUBO 계수에 넣습니다.

  $$P\Big(\sum x - 1\Big)^2 = P\Big(-\sum_v x_v + 2\sum_{u<v} x_u x_v + 1\Big)$$

- **벌점 크기**: 한 변수를 뒤집어 얻을 수 있는 목적함수의 최대 이득보다 조금 크게, 즉 '유효한 최소값'으로 둡니다.

  $$P = \left\lceil 1 + \max_i \Big(|q_{ii}| + \sum_j |q_{ij}|\Big)\right\rceil$$

  순열 문제에서는 실현 가능한 해의 모든 한 비트 이웃이 실현 불가능하므로, 벌점이 크면 풀이기가 그 장벽을 못 넘습니다. 작은 유효 벌점이 가장 좋았다는 결과(Ayodele 2022)를 따릅니다.
- **템플릿 두 개**: 앞 띠 작은방 수를 '들어가는 최대 개수'와 '하나 적게'로 두 QUBO를 만들어 예산을 나눠 풉니다. 에너지는 같은 템플릿끼리만 비교합니다.
- **해 → 평면**: 원-핫을 어긴 해는 탐욕적으로 복구하고, 안방이 가운데면 가까운 끝으로 옮긴 뒤, 앞·뒤 순서를 판상형 문법에 넣어 평면을 만들고 연속값(깊이·폭)을 30번 다듬어 J로 채점합니다.

코드: `src/generate/qubo.js`, `compare.js`

### 6.3 풀이기의 공통 계산

모든 풀이기는 같은 대칭 행렬(대각 q_ii, 비대각 q_ij)을 받습니다. 한 변수를 뒤집을 때의 에너지 변화와 그 갱신은 O(n)입니다.

$$\Delta_i = (1 - 2x_i)\Big(q_{ii} + \sum_{j\ne i} q_{ij}x_j\Big),\qquad \text{뒤집은 뒤: } \Delta_i \leftarrow -\Delta_i,\quad \Delta_j \mathrel{+}= (1 - 2x_j)\,q_{ij}\,(x_i^{\text{new}} - x_i^{\text{old}})$$

| 풀이기 | 계산 |
| --- | --- |
| tabu 공통(D²TS·PR·Memetic) | 가장 좋은 비-tabu 뒤집기를 고름(나빠져도). 뒤집은 변수는 n/50 + rand(1..10) 동안 금지, 최고해를 넘으면 예외(aspiration), 15n번 개선이 없으면 멈춤 |
| D²TS | tabu ↔ 섭동 반복. 엘리트 8개 중 하나에서 빈도 점수로 정렬한 변수를 순위 j에 대해 확률 ∝ j^−1.2로 n/4개 골라 뒤집음 |
| Path Relinking | 참조 해 10개 가운데 두 해 사이를 차이 변수를 하나씩 바꾸며 걷고, 1/3~2/3 지점을 tabu로 개선 |
| Memetic | 개체 20, 두 부모가 같은 비트는 유지·다른 비트는 무작위(균등 교차), 자식을 tabu로 개선 |
| Tabu(D-Wave 방식) | 다중 시작 tabu, tenure = min(20, ⌊n/4⌋), 한 번 읽기 20ms |
| SA | 메트로폴리스 수용 min(1, e^{−βΔ}). β는 ln2/(최대 변화)에서 ln100/(최소 계수)까지 기하 증가(1000 sweep), D-Wave 기본값 방식. 예산이 남으면 재시작 |
| Parallel Tempering | β 사다리 8단(기하)에서 각각 SA sweep, 이웃 사본 교환 확률 min(1, e^{(β_k − β_{k+1})(E_k − E_{k+1})}) |
| SQA | 이징으로 바꿔(s = 2x − 1, J_ij = q_ij/4, h_i = q_ii/2 + Σ_j q_ij/4) 사본 16개를 J⊥ = −(PT/2) ln tanh(Γ/PT)로 묶고 Γ를 2.5 → 0.01로 줄이며 메트로폴리스 |
| Simulated Bifurcation | dSB: y_i += (−(1 − a(t))x_i + c_0 Σ_j K_ij sgn x_j)Δt, x_i += y_i Δt, \|x_i\| > 1이면 벽. K = −J, 일차 항은 +1 고정 보조 스핀, c_0 = 0.5/(rms(K)√N) |
| CP-SAT 방식 | 칸을 차례로 채우는 분기한정. 하한 = 부분 에너지 + 남은 칸마다 가능한 최소 기여 + 남은 칸 쌍의 음수 결합 최솟값. 하한이 최고해 이상이면 가지치기 |
| 정확해(열거) | 원-핫을 지키는 모든 배정(m! × k!)의 에너지를 계산. 벌점이 유효하므로 QUBO 전역 최적 |

**공정한 비교**: 모든 풀이기에 같은 시간(브라우저) 또는 같은 시간을 기계에서 평가 횟수로 바꾼 고정 예산(벤치마크, 시드로 완전 재현)을 줍니다. 풀이 성능은 최적 도달률 p_s와 TTS₉₉로 봅니다.

$$\text{TTS}_{99} = t_{\text{run}}\cdot\frac{\ln 0.01}{\ln(1 - p_s)}\qquad(\text{Rønnow et al. 2014})$$

코드: `src/generate/solvers.js`, `scripts/qubo-benchmark.mjs`

## 7. QUBO 가중치를 평가 모델로 맞추기

**생각**: QUBO는 평가 모델의 대리(surrogate)입니다. 손으로 정한 가중치로는 QUBO 최적이 좋은 평면이 아니었습니다(에너지–점수 ρ = −0.21). 그런데 에너지(제약을 지키는 해에서는 벌점 0)가 가중치에 대해 선형이므로, 평가 모델 점수를 보고 가중치를 다시 정할 수 있습니다.

$$E(x) = \sum_t w_t\,\phi_t(x) = \mathbf{w}^\top\boldsymbol{\phi}(x)\quad(\text{제약을 지키는 } x)$$

**데이터**: 조건 20개(59~114㎡, 방 2~4개, 선호 5가지) × 템플릿 2개의 배치를 열거하거나(600개 이하) 600개 표본추출해, 각 배치를 평면으로 풀고 J를 잽니다(배치 9,567개). 같은 QUBO 안에서만 에너지를 비교하므로 조건·템플릿마다 그룹으로 묶습니다.

**방법 1 — 릿지 회귀(전체 순서 맞추기)**: 그룹마다 J를 백분위 순위 y로, φ를 그룹 평균으로 중심화해 다음을 풉니다.

$$\boldsymbol\beta = (X^\top X + \lambda I)^{-1}X^\top y,\qquad \mathbf w = -\boldsymbol\beta\ (\text{낮은 에너지} = \text{높은 점수})$$

**방법 2 — 직접(최적 평면 맞추기)**: 실제로 쓰는 것은 '에너지 최소 배치'이므로, 그 배치의 후회를 바로 줄입니다.

$$\text{후회}(\mathbf w) = \frac{1}{|G|}\sum_{g}\left(J\big(\arg\min_{x\in g}\mathbf w^\top\boldsymbol\phi(x)\big) - \max_{x\in g} J(x)\right)$$

(에너지 동점이면 그 평균.) 후회는 계단 함수라 경사가 없어서, 손 가중치와 릿지 해에서 출발해 가중치 1~3개를 무작위로 흔들고 '후회 − 2ρ'가 나빠지지 않으면 받아들이는 국소 탐색을 1,500번 합니다.

**검증**: 조건을 통째로 빼고 맞추는 5겹 교차검증으로 방법을 고릅니다. 빼 둔 조건에서 손 가중치는 ρ −0.33·후회 −16.1, 릿지는 ρ −0.55·후회 −18.4(순서는 맞추지만 최적 평면은 나빠짐), **직접은 ρ −0.53·후회 −10.6**이라 직접을 씁니다. 30시드 벤치마크에서 QUBO 경로 평면의 모델 점수가 약 3점 올라 직접 탐색과 같은 수준(86.2)이 됐습니다.

코드: `scripts/qubo-calibrate.mjs` → `src/generate/qubo-weights.js`, 결과 [`results/qubo-calibration.md`](results/qubo-calibration.md)
